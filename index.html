Work

Trimly

A multi-tenant booking platform I built on my own for independent salons and barbershops. Its AI agents answer clients over SMS, WhatsApp, email and voice, at any hour, and book them in.

I shipped Claude tool-use agents with Zod-validated inputs, webhook idempotency guards so a retried webhook never books twice, Stripe billing and real-time Socket.io streaming, all wrapped as a native app with Capacitor.

React 19 · TypeScript · Node.js · PostgreSQL · Claude API · Currently on hold

SubTrak

A mobile app that tracks every subscription you pay for and flags the ones you have stopped using. I am the project manager for our team in Farmingdale's CSC 325 capstone.

I run sprint planning and the backlog across a Django REST Framework backend, MongoDB and a React Native app. In progress.

Django REST Framework · MongoDB · React Native · Repository

A ReAct agent, from scratch

An agent in plain JavaScript with no framework: only the loop of thinking, calling a tool and reading the result, written by hand so I could see how an agent actually reasons.

Raw tool-calling logic, a tool registry and a stop condition, with every step of its reasoning printed as it runs.

JavaScript · LLM tool calling

Movie recommender

A REST API that suggests films from what you have already rated, trained with collaborative filtering on the MovieLens dataset.

I added backend caching and reworked the data pipeline so answers come back quickly under load.

Python · SQL · REST · Repository

OSINT investigation

A digital forensics investigation built only from open sources, where every finding is traced back to the place it was found.

Collecting, verifying and documenting evidence the way an analyst would, so someone else can follow the trail and reach the same answer.

OSINT · Digital forensics · Threat analysis

A note from me

I'm a third-year computer science student at Farmingdale State College, with a 3.6 GPA and places on the President's List and the Dean's List. I learn by building, and I like owning the whole stack.

That means caring about how an agent decides what to do, where its data lives, how it gets billed and where it can break. Trimly taught me most of that, one webhook at a time.

Before software I spent my time on cybersecurity and digital forensics, and it still shapes how I build: I assume the input is hostile and check it before anything acts on it.

I'm the first in my family to go to college, so I've worked most of this out on my own. This fall I'm an AI Engineering Fellow at CodePath, and I'm a member of the Cybersecurity Club and the South Asian Student Association.

I'm looking for internships in software engineering, AI and ML, or security, ideally on a team that works on infrastructure, agents or applied ML. I'm always glad to talk about AI, security, or breaking into tech as a first-gen student.
